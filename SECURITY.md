# Security

EOAI is a research sandbox. It uses synthetic data only and makes no
real payments, transfers or external writes.

If you find a way for an agent or improvement component to read
private answers, escape the sandbox, bypass tenant isolation or
authorization, or commit a write the gateway should reject, please
report it privately through
[GitHub security advisories](https://github.com/Aaryan1524/EOAI/security/advisories/new)
rather than a public issue.
